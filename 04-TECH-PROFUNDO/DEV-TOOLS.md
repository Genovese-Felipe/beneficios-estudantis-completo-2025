# Deep Dive on Development Tools

## JetBrains Student License
- All JetBrains IDEs are available for free for students:
  - IntelliJ IDEA
  - PyCharm
  - WebStorm
  - DataGrip
  - CLion
- **Complete Setup Guide:**
  1. Sign up for a JetBrains account.
  2. Verify your student status using a valid educational email.
  3. Download and install the IDE of your choice.
  4. Activate using your JetBrains account.
- **Best Plugins:**
  - Lombok Plugin
  - CheckStyle-IDEA
  - JRebel

## GitHub Copilot for Students
- **Free with GitHub Education Pack:**
  - Access GitHub Copilot at no cost for students.
- **Setup Guide:**
  1. Go to GitHub Copilot page.
  2. Click on `Sign Up` and follow the prompts.
- **Prompting Tips:**
  - Be specific with your requests.
  - Use comments to guide the AI.
- **Comparison with Alternatives:**
  - TabNine: Limited vs. Copilot's extensive code context.
