## Por que "00-FUNDAMENTOS" ao invés de "99-REGISTROS-HISTORICOS"?

**Nome anterior**: `99-REGISTROS-HISTORICOS` (Registros Históricos)
**Nome novo**: `00-FUNDAMENTOS` (Fundamentos)

**Motivos**:
1. **Ordem lógica**: Estes são documentos fundamentais que informam tudo mais, devem vir primeiro (00) não por último (99)
2. **Melhor semântica**: "Fundamentos" descreve melhor o conteúdo que serve de base para todo o projeto
3. **Navegação intuitiva**: Usuários naturalmente começam em 00 ao explorar pastas numeradas
4. **Consistência**: Alinha com práticas padrão onde 00 representa base/núcleo/fundação
