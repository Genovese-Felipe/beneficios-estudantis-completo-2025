Como Aplicar

Guia completo passo a passo para obter todos os benefícios estudantis

1

Prepare sua Documentação

Tenha em mãos seu e-mail institucional (.edu, .edu.br) ou comprovante de matrícula atualizado da sua instituição de ensino.

  • E-mail institucional ativo
  • Comprovante de matrícula (se necessário)
  • Documento de identidade
  • Conta no GitHub (gratuita)
2

Solicite o GitHub Student Pack

Acesse o site do GitHub Education e faça sua solicitação. É o ponto de partida para a maioria dos benefícios.

3

Solicite Outros Benefícios

4

Aproveite os Benefícios

Comece a usar suas ferramentas gratuitas e lembre-se de renovar anualmente enquanto for estudante.

💡 Dicas Importantes:

  • Mantenha seu e-mail institucional ativo
  • Renove anualmente os benefícios
  • Use as ferramentas para projetos pessoais
  • Construa seu portfólio profissional

❓ Perguntas Frequentes

Posso usar se estudo em universidade particular?
Sim! O GitHub Student Pack aceita estudantes de instituições públicas e privadas, desde que sejam credenciadas. Universidades, faculdades, cursos técnicos e até alguns cursos online são aceitos.
E se minha universidade não tem e-mail institucional?
Você pode usar um comprovante de matrícula ou carteirinha estudantil como alternativa. O GitHub aceita documentos que comprovem seu status de estudante.
Quanto tempo demora para ser aprovado?
Com e-mail institucional, a aprovação geralmente é instantânea. Com documentos, pode levar de 3 a 7 dias úteis para análise manual.
Posso usar as ferramentas comercialmente?
Depende da ferramenta. O GitHub Pro e JetBrains permitem uso comercial limitado. Sempre verifique os termos específicos de cada ferramenta.
