## How to Get Started

1. **Verify Student Status**
   - Visit: https://education.github.com/pack
   - Use your institutional email (@.edu, @.edu.br)
   - Upload proof of enrollment if needed

2. **Activate GitHub Copilot**
   - Settings → Copilot → Enable for Students
   - Install extension in your IDE
   - Start coding with AI assistance

3. **Claim Partner Offers**
   - Browse all tools in the pack
   - Click "Get access" for each tool
   - Follow redemption instructions

4. **Renew Annually**
   - Benefits expire after 1-2 years
   - Re-verify student status
   - Benefits automatically renewed
