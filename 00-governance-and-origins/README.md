# 00-governance-and-origins

## Overview

This directory serves as the central repository for all governance, historical, and foundational materials that guide the project's development and maintenance. It contains the original conversations, extracted source materials, operational protocols, and reusable templates that define how this repository is managed.

## Purpose

- **Transparency**: Maintain a complete record of project decisions and their rationale
- **Traceability**: Track the evolution of ideas from initial conversations to implementation
- **Governance**: Establish clear protocols and standards for repository management
- **Knowledge Transfer**: Provide context for new contributors and AI assistants

## Directory Structure

### 01-conversations/
Raw conversation logs and meeting records that capture the original discussions, decisions, and brainstorming sessions. These serve as the primary source of truth for understanding project intent.

**Contents:**
- Original conversation logs (markdown, PDF, DOCX formats)
- Meeting minutes and decision records
- Brainstorming session outputs

### 02-source-extractions/
Clean, organized extractions of key information and requirements derived from conversations and external sources. These documents synthesize raw inputs into actionable insights.

**Contents:**
- Processed summaries of conversations
- Requirements documents
- Research findings
- Reference materials

### 03-protocols/
Operational protocols and guidelines that govern how the repository is organized, maintained, and evolved over time.

**Contents:**
- Repository reorganization protocols
- Naming conventions and standards
- Quality assurance procedures
- Governance policies

### 04-templates/
Reusable templates for documentation, reporting, and standardized processes across the repository.

**Contents:**
- Document templates
- Report structures
- Checklists and forms
- Standard operating procedures

## Usage Guidelines

### For Contributors
1. **Before making structural changes**: Review the protocols in `03-protocols/`
2. **When documenting decisions**: Add conversation logs to `01-conversations/`
3. **For new processes**: Create or adapt templates from `04-templates/`

### For AI Assistants
- Consult `ai_assistant_guide.yaml` for area-specific guidance
- Reference conversation logs to understand project context and intent
- Follow protocols when performing repository operations
- Use templates for consistent documentation

## Key Documents

- **PROCESSO-EXECUTIVO.md** (in 02-source-extractions): Executive summary of repository reorganization process
- **reorg-protocol.md** (in 03-protocols): Step-by-step protocol for repository reorganization
