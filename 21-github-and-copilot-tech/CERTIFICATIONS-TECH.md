### Dicas de Estudo

#### 1. Hands-On é Essencial
- 80% prática, 20% teoria
- Use Free Tiers à exaustão
- Documente tudo que faz

#### 2. Comunidades
- Discord: TechStudyNotebook, AWS Community Builders
- Reddit: r/AWSCertifications, r/kubernetes
- LinkedIn: Grupos de certificações

#### 3. Recursos Gratuitos Essenciais
- [freeCodeCamp](https://www.freecodecamp.org/) - Cursos completos
- [Udemy (espere promoções)](https://www.udemy.com/) - Cursos por $10-15
- [YouTube](https://www.youtube.com/) - Busque "full course" + nome da cert

#### 4. Practice Tests
- **Sempre faça**: Practice tests são cruciais
- Fontes confiáveis:
  - Tutorialsdojo (AWS)
  - Whizlabs (Multi-cloud)
  - MeasureUp (Microsoft)

#### 5. Documentação Oficial
- Leia a documentação oficial
- É gratuita e sempre atualizada
- Geralmente é permitida durante exames práticos (CKA, CKAD)

### Otimizando Custos

1. **Comece pelo grátis**
   - Azure fundamentals via MLSA
   - ISC2 CC
   - AWS Educate

2. **Aproveite descontos**
   - Passe na primeira: vouchers são 50% do custo
   - Descontos em bundles (ex: CKA + CKAD juntos)
   - Promoções sazonais (Black Friday, Cyber Monday)

3. **Créditos cloud**
   - Azure for Students: $100/ano
   - GCP: $300 iniciais
   - AWS Educate: $50-200

4. **Material de estudo**
   - Bibliotecas universitárias (O'Reilly via instituição)
   - GitHub Student Pack (DigitalOcean credits)
   - Coursera audit mode (grátis sem certificado)
